Updates & Roadmap

What's been done so far, and what's coming next.

Recent Updates

November 2026

  • Added Providers: pages for Amazon, Apple, ByteDance, Cloudflare, Google, Meta, Microsoft, Reddit, Snap and X Corp, plus a table of every provider and its root domains.
  • Recorded the owner of every domain. Search now finds domains by owner, so “Meta” finds fbcdn.net.
  • Added Search: find any domain as you type, from the search page or the search box in the menu.
  • Updated every A–Z and category page, now covering 2,089 domains.
  • Added six new categories: AI & Machine Learning; Device, Browser & App Store; Help, Docs & Support; Payments & Commerce; Productivity & Workspace; and Security & Privacy.
  • Added a domain count to the top of every list page.
  • Added the All Domains page.
  • Added the combined Domains Index for browsing by letter or by type.
